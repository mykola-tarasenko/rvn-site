# Локальна копія rvn.com.ua

Статична копія сайту ГО «Робимо вам нерви», зібрана 26.11.2026 з живого сайту
(конструктор Hostinger) з виправленнями за SEO-аудитом. Hostinger для роботи не потрібен.

## Як користуватися

```powershell
python build.py     # збирає сайт у теку dist/
python serve.py     # перегляд: http://localhost:8137
```

Потрібні Python 3.12+ і Pillow (`pip install Pillow`).

## Що де лежить

| Шлях | Що це |
| --- | --- |
| `source/rvn-dump.json` | Тексти й структура 14 сторінок, зняті з живого сайту |
| `source/img/` | 68 оригінальних зображень (25 МБ) |
| `source/policy.txt` | Текст політики конфіденційности з Google Doc |
| `source/drive/` | 49 світлин з Drive «1 Рівень_РВН / Фото з заходів» + `index.json` (подія, ID файлу) |
| `source/instagram/` | Обкладинки й підписи дописів Instagram; `slides/` — усі слайди каруселей (32), `video/` — рилз про «Просвіту» |
| `content.py` | Нові тексти й дані: цифри, «Про нас», «Долучитися», «Підтримати», архів подій, новини |
| `build.py` | Генератор: шаблони сторінок, обробка зображень, sitemap, перенаправлення |
| `style.css` | Стилі (кольори й шрифт як на сайті, адаптивна сітка) |
| `site.js` | Поведінка: меню, каруселі, перегляд світлин, фільтри блоґу, зміст, поширення |
| `serve.py` | Локальний сервер, що імітує хостинг (чисті адреси, 301, 404) |
| `dist/` | Готовий сайт — саме цю теку викладати на хостинг |

Тексти головних сторінок беруться з `rvn-dump.json`; статті генеруються з нього повністю.
Щоб змінити текст статті, зручніше правити шаблон або дані й перезібрати.

## Що виправлено порівняно з версією в Hostinger

- **Адреси**: `/-` → `/yak-deputaty-zalyshaiut-odesu-bez-rishen`, `/----` → `/oun-na-odeshchyni`,
  `/blog-post` → `/100-richchia-niny-strokatoi`; 301 зі старих адрес; без слеша в кінці.
- **Сторінка 404** українською, з навігацією, код відповіді 404.
- **Дати** у форматі «24 листопада 2026 р.» з розміткою `<time>`.
- **Заголовки**: один H1 на сторінці, далі H2 і H3 без пропусків рівнів; абзаци більше не заголовки.
- **Alt** у всіх зображень, зокрема в галереях і на першому екрані; обкладинки карток мають порожній alt,
  бо поруч стоїть посилання-заголовок.
- **Підписи «До» і «Після»** під кожною парою вивісок.
- **Картки статистики** — текстом, а не картинками.
- **Зображення**: WebP кількох розмірів, `srcset`/`sizes`, `width`/`height`, ліниве завантаження;
  перше зображення сторінки вантажиться одразу. Усі зображення разом — 8 МБ замість 25.
- **Метадані**: суфікс «| РВН», canonical, Open Graph, JSON-LD (Organization, Article, Blog), `sitemap.xml`, `robots.txt`.
- **Доступність**: `aria-label` для логотипа й соцмереж, посилання «Перейти до вмісту», мобільне меню з `aria-expanded`.
- **Блоґ**: усі 9 статей у HTML однієї сторінки, без посторінкового розбиття.
- **Стаття про Майдан**: повторне фото прибрано.
- **Політика конфіденційности** — власна сторінка `/privacy` замість посилання на Google Doc.

## Дизайн (оновлення 26.11.2026)

- Шапка закріплена вгорі; активний розділ меню виділено; на телефоні — меню-«гамбургер» з анімацією.
- Перший екран: фото з градієнтним затемненням замість напівпрозорості, більший заголовок.
- Картки статей, медія й способів зв'язку — «панелі» з тінню, вся картка клікабельна.
- Блоґ: остання стаття виділена великою карткою.
- Статті: хлібні крихти, рубрика, автор з ініціалами, час читання, попередня й наступна стаття.
- Мовні інспекції: пари «До/Після» з мітками на фото, три пари в ряд.
- Контакти: новий блок «Як долучитися» з чотирма діями (анкета, скарга, лист, підтримка).
  Короткі описи в ньому написано заново — їх варто погодити.
- Підвал: логотип, опис, розділи, контакти, рядок з ©.
- Червоні й сині тла трохи затемнено (`--red-sec`, `--blue-sec`), щоб світлий текст на них читався
  відповідно до вимог контрастности; фірмові червоний і блакитний лишилися для кнопок і акцентів.

## Зручність (UX/UI, оновлення 26.11.2026)

Поведінка — у `site.js` (без бібліотек; без JavaScript сайт теж працює).

- **Шапка**: поруч із логотипом — назва «Робимо вам нерви». На телефоні меню відкривається на весь екран,
  закривається клавішею Esc або після вибору розділу; сторінка під ним не прокручується.
- **Головна**: під першим екраном — три швидкі дії (повідомити про порушення, долучитися, підтримати);
  у блоці «Блоґ» три останні статті замість шести, щоб сторінка була коротшою.
- **Блоґ**: рубрики-фільтри з кількістю статей і пошук за назвою, автором чи темою; рубрику можна передати
  посиланням (`/blog?rubryka=istoriia`). Рубрика в статті веде на відфільтрований блоґ.
- **Статті**: смужка прогресу читання, зміст для статей із трьома й більше розділами (підсвічує поточний),
  кнопки «Поділитися» (Telegram, Facebook, копіювати посилання, инші застосунки на телефоні),
  «Читайте також» спершу зі статей тієї ж рубрики.
- **Світлини**: у статтях, каруселях, архіві подій, парах «До/Після» й галереях світлину можна відкрити
  на весь екран; гортання стрілками, клавішами чи пальцем, закриття Esc.
- **Скрізь**: кнопка «вгору», копіювання пошти на сторінці контактів, RSS блоґу в підвалі, без повтору посилання на політику.

## Викладання на хостинг

У `dist/` уже лежать правила для двох типів хостингу:

- `.htaccess` — для Apache (звичайний віртуальний хостинг, наприклад NIC.UA): чисті адреси, 301, сторінка 404.
- `_redirects` — для Netlify або Cloudflare Pages (чисті адреси там працюють самі).

Після викладання перевірити: `/blog` відкривається без `.html`, `/-` перенаправляє на нову адресу з кодом 301,
неіснуюча адреса віддає код 404.

## Попередній перегляд на GitHub Pages

Репозиторій `mykola-tarasenko/rvn-site`; після кожного надсилання в гілку `main` GitHub Actions
(`.github/workflows/pages.yml`) збирає сайт і викладає його на https://mykola-tarasenko.github.io/rvn-site/.

- Збирання з `RVN_BASE=/rvn-site` додає підтеку до всіх внутрішніх адрес; `RVN_NOINDEX=1` закриває
  сторінки від пошуковиків (`noindex`), щоб копія не конкурувала з rvn.com.ua. Canonical і sitemap
  вказують на rvn.com.ua.
- GitHub Pages не вміє 301, тому старі адреси статей (`/-`, `/----`, `/blog-post`) перенаправляє HTML-сторінка.
- Локально так само: `RVN_BASE=/rvn-site RVN_NOINDEX=1 python build.py` (у Git Bash додати `MSYS_NO_PATHCONV=1`).
